## 1. PURPOSE OF THE CONTROL BUNDLE
The Control Bundle replaces unstructured prompting with a durable, machine-readable, bundle-governed state machine. It enforces human sovereignty, autonomous local repair, corpus-first discipline, authority separation, and state persistence.

---

## 2. GOVERNANCE ARTIFACT CLASSIFICATION

### Class A: Human Governance Artifacts (Human-Sovereign)
- `01_AUTHORITY_HIERARCHY.md` — Hierarchical boundaries of epistemic authority.
- `02_ARCHITECTURE_LOCK.md` — Canonical paragraph spine.
- `03_CORPUS_AND_SOURCE_PERIMETER.md` — Permitted literature corpus.
- `04_CLAIM_PROVENANCE_AND_STATUS_RULES.md` — Epistemic taxonomy and status semantics.
- `05_AUTONOMOUS_LOOP_POLICY.md` — Autonomous repair bounds (max 4 cycles).
- `06_HUMAN_SOVEREIGNTY_GATES.md` — Mandatory escalation triggers and human reserved powers.
- `09_HUMAN_RATIFICATION_LEDGER.md` — Immutable historical ledger of explicit human locks.

### Class B: Evidence Artifacts (Evidence-Governed)
- `03_source_notes/` (`SRC_*.md`) — Saturated single-source extraction records.
- `04_cluster_notes/` (`CLUS_*.md`) — Saturated comparative cluster adjudications (`CCC_*`).
- `05_synthesis_notes/` (`SYNTH_*.md`) — Cross-cluster thematic syntheses.
- `06_paragraph_ledgers/` (`LEDGER_P*.md`) — Structured proposition slots.
- `07_argument_assembly/` (`ASSEMBLY_P*.md`) — Argumentative choreography.
- `08_staged_prose/` (`STAGED_P*.md`) — Restrained boundary-stabilized prose.
- `09_manuscript_prose/` — Final manuscript prose.
- `07_reports/` — Iteration ledgers, audits, and walkthroughs.

### Class C: Machine State Artifacts (Agent-Updated During Passes)
- `08_CURRENT_STATE.yaml` — Machine-readable state machine.
- `10_ESCALATION_QUEUE.md` — Blocked or ambiguous decisions awaiting human review.
- `11_RUN_LOG.jsonl` — Append-only execution telemetry log.
- `07_reports/CURRENT_RATIFICATION_PACKET.md` — Primary human-facing return artifact.
